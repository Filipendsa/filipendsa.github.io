# 📄 Modelo de Currículo Profissional (HTML para PDF)

Este projeto contém um currículo profissional em HTML, CSS e JavaScript otimizado especificamente para exportação em PDF de alta qualidade e formato A4.

## 🚀 Como Usar

1. **Abrir no Navegador:**
   - Dê um duplo clique no arquivo `index.html` ou abra com o Chrome, Edge, Firefox, Brave, etc.
   - Caminho local: `C:\Users\finog\.gemini\antigravity-ide\scratch\curriculo\index.html`

2. **Editar as Informações:**
   - Clique no botão **"✏️ Editar Conteúdo"** na barra superior.
   - Clique em qualquer texto (nome, cargo, e-mail, experiências, habilidades) e digite suas informações reais diretamente na página.
   - Clique em **"💾 Salvar Rascunho"** (ou use `Ctrl + S`) para não perder suas alterações se fechar o navegador.

3. **Trocar Paleta de Cores:**
   - Na barra superior, você pode alternar entre 5 temas visuais profissionais:
     - 🔵 **Azul Marinho Executivo** (Padrão corporativo e de tecnologia)
     - 🟢 **Verde Esmeralda** (Moderno e dinâmico)
     - 🟣 **Índigo Tech** (Criativo e contemporâneo)
     - ⚫ **Cinza Grafite** (Minimalista e sóbrio)
     - 🔴 **Bordô Elegante** (Executivo sênior)

4. **Baixar como PDF:**
   - Clique no botão azul **"📥 Baixar como PDF"** (ou pressione `Ctrl + P`).
   - Na janela de impressão que abrir:
     - **Destino:** Escolha **"Salvar como PDF"** (ou *Microsoft Print to PDF*).
     - **Tamanho do Papel:** **A4**.
     - **Margens:** **Padrão** ou **Nenhuma**.
     - **Mais Definições / Opções:** Marque a caixa **"Gráficos de segundo plano"** (para preservar as cores do cabeçalho e badges).
   - Clique em **Salvar**.

## 📁 Arquivos do Projeto

- `index.html`: Estrutura semântica e acessível do currículo com ícones SVG inline.
- `style.css`: Estilização refinada, variáveis CSS e regras de `@media print` para ajuste milimétrico em folha A4.
- `script.js`: Sistema de edição ao vivo, troca de temas e persistência em `localStorage`.
